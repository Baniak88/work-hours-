# Android — instalacja Work Hours

[Pobierz APK bez logowania](https://expo.dev/artifacts/eas/3mJDd4vz2LMKdZ1kbvkCKtszIqd17WQsxAfceEsWLgg.apk) lub pobierz plik APK z [wydania 1.9.5](https://github.com/Baniak88/work-hours-/releases/tag/v1.9.5) lub udostępnij odbiorcy bezpośredni link podany w tym wydaniu. Repozytorium GitHub jest publiczne, więc plik można pobrać bez logowania. Link do pobrania z Expo można wysłać przez e-mail lub WhatsApp; odbiorca nie potrzebuje konta Expo.

Na Androidzie otwórz pobrany plik APK i zatwierdź instalację. Jeśli system o to poprosi, zezwól przeglądarce lub menedżerowi plików na instalację aplikacji z tego źródła. Wcześniejszą wersję zaktualizuj bez odinstalowywania, aby zachować dane.

APK ma około 91 MB, więc może przekroczyć limit załączników e-mail. Link do pobrania jest wygodniejszy do przesłania. Każda osoba przechowuje swoje dane na własnym urządzeniu.

Wersja 1.9.5 nie zawiera korekty salda, która jest przygotowana w kodzie 1.9.6.
