# Android — instalacja Work Hours

[Pobierz APK bez logowania](https://expo.dev/artifacts/eas/HYK7EIMH2rKu1F35lvgwflLy7IhofGp_FIG2FCT21XI.apk) lub pobierz plik APK z [wydania 1.8.0](https://github.com/Baniak88/work-hours-/releases/tag/v1.8.0) lub udostępnij odbiorcy bezpośredni link podany w tym wydaniu. Repozytorium GitHub jest prywatne, więc plik z GitHuba wymaga dostępu do repozytorium. Link do pobrania z Expo można wysłać przez e-mail lub WhatsApp; odbiorca nie potrzebuje konta Expo.

Na Androidzie otwórz pobrany plik APK i zatwierdź instalację. Jeśli system o to poprosi, zezwól przeglądarce lub menedżerowi plików na instalację aplikacji z tego źródła. Wcześniejszą wersję zaktualizuj bez odinstalowywania, aby zachować dane.

APK ma około 91 MB, więc może przekroczyć limit załączników e-mail. Link do pobrania jest wygodniejszy do przesłania. Każda osoba przechowuje swoje dane na własnym urządzeniu.
