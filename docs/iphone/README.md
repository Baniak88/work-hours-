# iPhone — instalacja Work Hours

Wyślij link: https://work-hours-osobiste.daintypersimmon4.chatgpt.site

Otwórz go na iPhonie w Safari, wybierz **Udostępnij → Do ekranu początkowego → Dodaj**, następnie uruchom aplikację z dodanej ikony. Pierwsze pobranie wymaga internetu; po przygotowaniu do pracy offline aplikacja działa bez sieci. Dane są zapisane osobno na każdym urządzeniu.

To wersja instalowana z Safari, bez App Store i konta Apple Developer. Plik APK działa wyłącznie na Androidzie. Aktualizacja wersji z Safari wymaga internetu oraz zamknięcia i ponownego otwarcia okien aplikacji.

## Publikacja z GitHub Pages

Repozytorium zawiera workflow „Publish iPhone web app” budujący wersję dla adresu `https://baniak88.github.io/work-hours-/`. Właściciel repozytorium musi najpierw w ustawieniach **Settings → Pages → Build and deployment → Source** wybrać **GitHub Actions**, a następnie uruchomić workflow. Do czasu zakończenia publikacji ten adres może być niedostępny.

Nowy adres ma osobne dane lokalne. Aby przenieść wcześniejsze wpisy, zapisz kopię JSON w starej aplikacji i przywróć ją w nowej. Przywrócenie zastępuje dane w miejscu docelowym.
